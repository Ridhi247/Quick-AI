# 🤖 Quick AI – AI SaaS Platform

Quick AI is a full-stack AI-powered SaaS web application that provides a suite of intelligent tools for content generation, image processing, and document analysis. It includes secure authentication, subscription-based access, and a scalable cloud database.

---

## 🚀 Features

### 🔐 Authentication & Billing (Clerk)
- Secure login and signup (Email + Google)
- User profile and account management
- Subscription-based premium access
### 🧠 AI Tools
- Article Generator – Generate AI-based articles
- Blog Title Generator – Create blog titles from keywords
- Image Generator – Generate images from prompts (premium)
- Background Remover – Remove image backgrounds
- Object Remover – Remove unwanted objects
- Resume Analyzer – Upload resumes for AI-based review
### 📊 Additional Features
- Dashboard with user creation history
- Community page with public images and like functionality
- Fully responsive modern UI
### 🗄️ Backend API (Express + PostgreSQL)
- RESTful APIs for AI workflows
- Secure middleware and request handling
- Serverless PostgreSQL (Neon) database
### 🎨 Frontend (React + Vite)
- Modern responsive UI
- Fast rendering with Vite
- Seamless API integration

## 🔧 Installation
### 1️⃣ Clone the repository
git clone https://github.com/Ridhi247/Quick-AI.git
cd Quick-AI
### 2️⃣ Install frontend dependencies
cd client
npm install
### 3️⃣ Install backend dependencies
cd ../server
npm install

---

## ▶️ Run Locally
## Backend
cd server
npm start
## Frontend
cd client
npm run dev
